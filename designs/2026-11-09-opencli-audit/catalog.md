**2. Do not copy**
- Strategy label PUBLIC/COOKIE/etc. as the routing signal: autobrowse's `via` is derived from live tokens, and OpenCLI's label never drives routing.
- Regex-matched module discovery (`discovery.ts:30`): a text pattern decides what counts as a command, which breaks on renamed helpers. We have typed lists.
- Last-registered-wins by name (`registry.ts:222-238`, `main.ts:112`): silent overrides are worse than our explicit blockers and standing.
- Plugin install with no integrity check (`plugin.ts:703`; `--ignore-scripts` only covers install-time scripts): our `sha256` plus `--trust` is stricter.
- A global registry on `globalThis` (`registry.ts:127-129`): a workaround for module duplication.
- `.ts` and YAML adapter ignore-warnings (`discovery.ts:182,258-301`): a migration scar, no value for us.
- Flat `Arg` coercion (`execution.ts:53-96`): it silently passes strings for any type other than int/number/bool. Zod is stricter.
- `defaultFormat: json` for every command (`commanderAdapter.ts:56`): our callers are services, not terminals.

**3. Three highest-value upgrades, in order**
1. Give hand-written `BrowserFlow` a zod `input` and `summary` (`browser/flow.ts:243`), so `abilities` and the `do` picker stop showing `inputs: []` and `do` can route into flows. Size M.
2. Emit a committed `catalog.json` (the `abilitiesOf` rows plus JSON Schema). Add a CI test that fails on silently dropped routes, flows or workflows, and use it for paged `abilities --site/--kind/--ready` and per-route help. Size S.
3. Add before/after-call hooks and allow a mod to register a `SiteApi` (today `SITES` in `sites/index.ts:80` is closed), reusing the existing sha256 and `--trust` model. Size M.
