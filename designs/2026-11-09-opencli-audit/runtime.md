## 2. Do not copy

- **`chrome.debugger` attach with retries** (`extension/src/cdp.ts:116-150`): it only works around other extensions grabbing the debugger. Patchright has no such contention.
- **Fixed shared daemon on port 19825**: one daemon for everyone, never exits (`daemon.ts:17-20`).
- **SIGKILL of the pid reported by `/status`** (`browser/daemon-lifecycle.ts:118-121`): it trusts an unauthenticated claim.
- **Fail-fast 409 `session_busy`** (`daemon.ts:457-470`): autobrowse's durable wait suits scheduled writes better (`profile-wait.ts:145`).
- **Global `OPENCLI_CDP_ENDPOINT` factory switch** (`runtime.ts:12-15`): autobrowse routes per site (`own.ts:90`).
- **Parking released tabs on about:blank or an idle page inside the user's Chrome** (`background.ts:2228-2240`): it is a visible side effect that only suits their model.
- **Journal version gating** (`daemon-client.ts:149-166`): compatibility cruft for extension skew that autobrowse has no equivalent of.
- **Lease TTL held only in memory**: autobrowse's `SingletonLock` (`browsers.ts:120`) is already OS-level and outlives the process.

## 3. Top three upgrades

1. **Command-id idempotency on the explore loopback** (`explore/server.ts`), with an unknown-outcome answer when the browser dies mid-act. A timed-out `click` or submit retried by an agent can currently run twice.
2. **Own-browser tab hygiene**: a dedicated background window, a `{pid, targetId}` ledger, and stale-tab reap in `session.ts`, `own.ts` and `reap.ts`. A crash today leaves tabs in the person's real browser.
3. **Read-only tab pool per profile** with a bounded admission queue (`flow.ts:662`). This gives concurrent reads without a second browser, while writes stay serial. Quick wins to batch in: stamp explorer version and warn on skew (S), and put the holder's op and age in `ProfileBusy` (S).
